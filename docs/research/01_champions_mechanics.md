# 調査1: チャンピオンズの仕様と本編との違い（§9-1）

取得日: 2026-10-22。数値は攻略サイト・ファンサイト由来で、公式資料では未照合。

## 実数値（出典: GameWith 546449）

| 項目 | チャンピオンズ | 本編 |
|---|---|---|
| レベル | 50 固定 | 可変 |
| 個体値 | 31 固定 | 0〜31 |
| 努力値 → 能力ポイント | 1能力 最大32、合計66。1ポイント = 実数値+1 | Lv50 で努力値8 = +1 |
| HP | 種族値 + 75 + 能力ポイント | (種族値×2+個体+努力/4)×Lv/100+Lv+10 |
| HP以外 | floor((種族値 + 20 + 能力ポイント) × 能力補正) | 同様の式×性格補正 |
| 性格（公式名「能力補正」） | 1.1 / 0.9 | 同じ |

※ Lv50・個体31 の本編の式と整合する（種族値+75 / +20 は Lv50・個体31 の定数部分）。

## 状態異常（出典: GameWith 546478, 554395 / ねむりは 554395）

| 状態 | チャンピオンズ | 本編との違い |
|---|---|---|
| まひ | 行動不能 1/8、素早さ 1/2 | 本編は 1/4 |
| ねむり | 1回目は必ず行動不能、2回目 1/3 で回復、3回目は必ず回復。ねむるは3回目まで回復しない | 本編は1〜3ターンで均等にランダム |
| こおり | 行動前に 25% で回復、3ターン目は必ず回復 | 本編は 20%、上限なし |
| やけど | 1/16、物理 1/2 | 同じ |
| どく / もうどく | 1/8 / 1/16ずつ増加 | 同じ |
| こんらん | 1/3 で自傷（威力40）、1〜4ターン | 同じ（本編 Gen7以降と同じ） |

## ダメージ計算（出典: GameWith 554133 の計算機の更新履歴）

- 乱数幅・補正の掛け順・端数処理の記載はなし → **仮: 本編準拠**。
- 技の威力・タイプの変更あり（技ごとの一覧は未取得）。ポルターガイストは持ち物なしでも失敗しない。
- ステルスロック等が有効だとマルチスケイルは発動しない。
- きりさく系に シャドークロー・ドラゴンクロー が追加（出典: bulbagarden スレッド。未照合）。

## ルール（出典: champdex.com/guides/format-rules）

- 6匹見せ4匹選出（シングルは要確認）。チーム公開。
- 持ち時間: 選出 90秒 / 1ターン 45秒 / 持ち時間 7分 / 試合 20分で引き分け。
- 時間切れは引き分け（本編と違う）。
- レギュレーション M-C: 2026-09-09 〜 2026-12-02。メガシンカあり。

## 大きな発見: 既存ライブラリが対応済み

- `@smogon/calc` 0.12.0（2026-09-18 更新）は `gen.num = 0` でチャンピオンズを扱う（`calc/src/mechanics/util.ts`）。
  → §4 は自前で式を書くより、これを使って記録で答え合わせする方が早い。
- Pokémon Showdown に `mod: 'champions'` があり、OU / UU / Doubles / BSS / VGC の形式がある。
  → §5 のシミュレータは Showdown の champions mod を使える見込み。
